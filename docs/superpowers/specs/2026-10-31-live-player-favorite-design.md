# 直播播放页收藏设计

## 目标

在电视直播播放页右上角提供收藏入口，使“我的直播源”和“在线频道库”的频道无需返回电视列表即可收藏或取消收藏。

## 交互与布局

- 收藏按钮位于右上角控制区，沿用播放页现有 44x44 直角按钮样式。
- M3U 直播播放页同时显示收藏按钮和频道列表按钮；收藏在左，频道列表在最右，间距 8。
- 在线频道库直播播放页只显示收藏按钮。
- 收藏后显示实心星标，未收藏时显示描边星标。
- 收藏按钮跟随播放页其他控件在 5 秒后自动隐藏，点击屏幕后重新显示并重新计时。
- 点击收藏按钮时阻止事件冒泡到播放区域，不改变控件计时或播放状态。

## 数据与状态

- 复用现有 `useUserData().isLiveFavorite` 和 `toggleLiveFavorite`。
- M3U 频道以 `kind = 'm3u'` 和 `channelUrl` 作为唯一键。
- 在线频道库以 `kind = 'library'` 和 `channelId` 作为唯一键。
- M3U 收藏保存当前直播源 ID、源名称和频道 Logo。
- 在线频道库收藏保存 `sourceName = '在线频道库'`。
- 收藏失败时保留原状态并输出警告，不中断正在播放的视频。

## 验证

- 类型检查和现有测试通过。
- Android release 构建成功。
- 在手机上分别从两种来源进入播放页，验证收藏、取消收藏、图标状态以及“我的收藏”同步。
